## CINEHUB 미니 프로젝트 프론트엔드 UI 개선 및 DB 연동 구조 정리

📌 학습일 : 2026.08.26

📌 학습 내용 : CINEHUB 화면 구성, HTML/CSS UI 통일, 메뉴 활성화 효과, 게시글 상세 UI 수정, 데이터베이스 테이블 구조, Java·Oracle 연동 흐름

#### 1. CINEHUB 프론트엔드 화면 구성 및 디자인 통일

CINEHUB 미니 프로젝트의 메인 페이지, 커뮤니티, 글쓰기, 게시글 수정, 게시글 상세, 관리자 페이지 등의 화면을 정리하였다.

- 기존 HTML 구조를 최대한 유지하면서 CSS 중심으로 디자인 수정
- 영화 커뮤니티 사이트에 어울리는 레이아웃과 색상 구성 적용
- 전체 배경은 연한 회색 계열로 구성
- 상단 헤더는 검은색 계열로 구성하여 영화 사이트 분위기 강조
- AI 추천 배너는 추후 실제 영화 데이터를 연동할 예정이므로 프론트 단계에서는 검은색 영역으로 구성
- 버튼, 입력창, 게시글 목록 등 페이지별 UI 스타일을 일관되게 조정

#### 2. 메뉴 선택 상태 표시

메뉴에 마우스를 올렸을 때만 표시되던 밑줄 효과를 현재 선택한 메뉴에서도 유지되도록 수정하였다.

```css
.admin-menu > a.active {
  color: var(--cine-accent);
}

.admin-menu > a.active::after {
  transform: scaleX(1);
}
```

현재 페이지에 해당하는 메뉴에 `active` 클래스를 적용하여 선택 상태를 표시한다.

```html
<a href="users.html" class="active">회원 관리</a>
```

- 커뮤니티 메뉴의 현재 카테고리 표시
- 관리자 페이지의 현재 메뉴 표시
- 다른 메뉴로 이동하면 기존 밑줄은 사라지고 이동한 메뉴에 밑줄 표시
- `::after`와 `transform: scaleX()`를 이용하여 기존 hover 효과와 동일한 형태로 구성

#### 3. 커뮤니티 카테고리 구조 정리

커뮤니티 메뉴는 각각 별도의 화면을 여러 개 만드는 방식보다 하나의 게시글 목록 화면에서 조회 조건을 변경하는 구조로 구성할 수 있다는 점을 정리하였다.

```text
전체
공지사항
영화리뷰
영화추천
자유토론
인기글
```

추후 Java와 DB를 연동하면 선택한 카테고리에 따라 해당 게시글만 조회하도록 처리한다.

```text
전체      → 전체 게시글 조회
공지사항  → 공지사항 조회
영화리뷰  → 영화리뷰 게시글 조회
영화추천  → 영화추천 게시글 조회
자유토론  → 자유토론 게시글 조회
인기글    → 인기 게시글 조회
```

게시글 상세 화면에서 수정·삭제 버튼과 댓글 관련 버튼의 스타일을 통일하였다.

```css
.author-actions button {
  width: auto;
  min-width: 0;
  height: auto;
  padding: 5px 10px;
}
```

- 수정·삭제 버튼을 답글·신고 버튼과 비슷한 크기로 조정
- 버튼 hover 및 클릭 효과 통일
- 게시글 본문과 댓글 영역 사이의 불필요한 가로선 제거
- 실제 HTML 클래스명인 `.author-actions`를 기준으로 스타일 적용

#### 5. 프론트엔드와 데이터베이스 연결 구조

HTML이 Oracle DB에 직접 연결되는 것이 아니라 Java 백엔드가 중간에서 데이터를 처리한다는 구조를 정리하였다.

```text
HTML / CSS / JavaScript
        ↓
     Java 백엔드
        ↓
       JDBC
        ↓
     Oracle DB
```

각 영역의 역할은 다음과 같다.

- HTML : 화면 구조
- CSS : 화면 디자인
- JavaScript : 사용자 동작 처리 및 서버 요청
- Java : 요청 처리 및 데이터 가공
- JDBC : Java와 Oracle DB 연결
- Oracle : 실제 데이터 저장 및 조회

#### 6. Java와 Oracle 연동 순서

전체 기능을 연결하기 전에 Java와 Oracle의 연결을 먼저 확인해야 한다.

```text
1. Oracle DB 테이블 생성
2. Java에서 JDBC를 이용해 Oracle 연결
3. Java에서 SELECT / INSERT 실행 확인
4. Java 백엔드 기능 작성
5. 프론트엔드에서 Java 백엔드 호출
6. Oracle의 데이터를 화면에 출력
```

최종 데이터 흐름은 다음과 같다.

```text
프론트엔드
   ↓ 요청
Java
   ↓ SQL 실행
Oracle
   ↓ 조회 결과
Java
   ↓ 결과 전달
프론트엔드
```

#### 7. CINEHUB 데이터베이스 테이블 구조 정리

CINEHUB에서 필요한 주요 데이터를 기준으로 테이블 구조를 확인하였다.

```text
USERS
MOVIES
BOARDS
CATEGORIES
POSTS
COMMENTS
NOTICES
```

게시글 기능에서는 사용자, 게시판, 카테고리, 영화 등의 데이터가 서로 연결되어 사용된다.

```text
USERS
  ↓
POSTS
  ├─ BOARDS
  ├─ CATEGORIES
  └─ MOVIES
       ↓
    COMMENTS
```

#### 8. 영화 데이터 및 AI 검색 기능 구조 확인

영화 정보는 DB에 저장하고, 추후 영화 검색 및 AI 추천 기능과 연결할 수 있도록 구조를 확인하였다.

- 영화 제목, 영문 제목, 줄거리 등의 데이터를 저장
- 영화 데이터를 벡터 형태로 변환하여 의미 기반 검색에 활용 가능
- Qdrant와 같은 벡터 DB를 이용하여 유사한 영화 검색 기능 구현 가능
- 프론트 단계에서는 실제 영화 포스터나 추천 데이터를 고정하지 않고 추후 백엔드 데이터로 교체할 수 있도록 영역만 구성

#### 핵심 정리

- CINEHUB의 여러 페이지 디자인을 CSS 중심으로 통일하였다.
- 메뉴의 현재 선택 상태를 `active` 클래스로 표시하는 방법을 적용하였다.
- 게시글 상세 페이지의 수정·삭제 버튼과 댓글 버튼 스타일을 통일하였다.
- 프론트엔드가 DB에 직접 연결되는 것이 아니라 Java 백엔드를 거쳐 Oracle과 통신한다는 구조를 이해하였다.
- DB 연동은 `Java ↔ Oracle` 연결을 먼저 완료한 뒤 `프론트 ↔ Java`를 연결하는 순서로 진행한다.
- 커뮤니티 카테고리는 화면을 여러 개 만드는 방식보다 DB 조회 조건을 변경하는 방식으로 구현할 수 있다.
- 영화 데이터와 AI 검색 기능은 추후 백엔드 및 벡터 DB와 연동할 수 있도록 확장 구조를 확인하였다.
