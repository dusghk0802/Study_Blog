#### 1. PDF에서 텍스트 추출

```python
import pymupdf
import os

doc = pymupdf.open(pdf_file_path)

full_text = ''
for page in doc:
    text = page.get_text()
    full_text += text

pdf_file_name = os.path.splitext(os.path.basename(pdf_file_path))[0]

with open(f"../output/{pdf_file_name}.txt", 'w', encoding='utf-8') as f:
    f.write(full_text)
```

`pymupdf.open()`으로 PDF를 열고, 페이지마다 `get_text()`로 글자를 추출해 하나의 문자열로 합친다.

`os.path.basename()`은 경로에서 파일 이름만, `os.path.splitext()[0]`은 확장자를 뺀 이름만 꺼내서 같은 이름의 `.txt` 파일로 저장할 수 있다.

#### 2. 헤더·푸터를 제외하고 추출

```python
header_height = 80
footer_height = 80

for page in doc:
    rect = page.rect
    text = page.get_text(clip=(0, header_height, rect.width, rect.height - footer_height))
    full_text += text + '\n------------------------------------\n'
```

논문 PDF는 페이지마다 학회 이름, 쪽 번호 같은 머리말·꼬리말이 반복되어 요약에 방해가 된다.

`page.rect`로 페이지 크기를 구하고, `get_text(clip=(x0, y0, x1, y1))`로 위아래 80만큼을 잘라낸 본문 영역만 추출했다.

#### 3. GPT로 문서 요약

```python
def summarize_txt(file_path: str):
    with open(file_path, 'r', encoding='utf-8') as f:
        txt = f.read()

    system_prompt = f'''
    너는 다음 글을 요약하는 봇이다. ...
    작성해야 하는 포맷은 다음과 같다.

    # 제목
    ## 저자의 문제 인식 및 주장 (15문장 이내)
    ## 저자 소개

    =============== 이하 텍스트 ===============
    { txt }
    '''

    response = client.chat.completions.create(
        model="gpt-4o",
        temperature=0.1,
        messages=[{"role": "system", "content": system_prompt}]
    )
    return response.choices[0].message.content
```

f-string으로 프롬프트 안에 문서 전체를 넣고, 결과 형식(제목, 문제 인식, 저자 소개)을 미리 정해 주면 원하는 구조로 요약을 받을 수 있다.

요약처럼 정확해야 하는 작업은 `temperature=0.1`로 낮게 설정한다.

`pdf_to_text()`와 `summarize_txt()`를 `summarize_pdf()` 하나로 묶으면 PDF 경로만 넣어 텍스트 추출부터 요약 저장까지 한 번에 처리할 수 있다.

`if __name__ == '__main__':` 아래에 실행 코드를 두면 파일을 직접 실행할 때만 동작하고, 다른 파일에서 함수만 불러다 쓸 수 있다.

#### 4. Whisper로 음성을 텍스트로 변환

with open(audio_file_path, 'rb') as audio_file:

`audio.transcriptions`는 음성을 말한 언어 그대로 받아 적고, `audio.translations`는 영어로 번역해서 받아 적는다.

음성 파일은 글자가 아니므로 `'rb'`(바이너리 읽기) 모드로 열어서 전달한다.

#### 5. 회의록 요약과 STT 오류 교정

```python
df = pd.read_csv("파일명.csv", sep='|')

name_dict = {"SPEAKER_00": "이름1", "SPEAKER_01": "이름2"}
df["name"] = df["speaker_id"].apply(lambda x: name_dict[x])

meeting_note_txt = df[['start', 'end', 'name', 'text']].to_json(orient='records', force_ascii=False)
```

화자 분리(RTTM) 결과에는 `SPEAKER_00`처럼 번호만 있어서, 딕셔너리와 `apply()`로 실제 이름을 붙였다.

`to_json(orient='records', force_ascii=False)`로 회의 내용을 한글이 깨지지 않는 JSON 문자열로 바꿔 프롬프트에 넣고, `# 회의 제목`, `## 주요 내용`, `## 참석자별 입장`, `## 결정 사항` 형식으로 요약했다.

STT는 잘못 받아 적는 경우가 있어서, 요약문과 전체 녹취록을 함께 넣고 문장마다 잘못된 부분만 고치도록 해 `corrected_text`를 만들었다.

#### 6. 회의록을 Word 파일로 저장

```python
from docx import Document

document = Document()
document.add_heading('제목', level=1)

table = document.add_table(rows=1, cols=2)
table.style = 'Table Grid'
hdr_cells = table.rows[0].cells
hdr_cells[0].text = '열이름1'
hdr_cells[1].text = '열이름2'

for row in 데이터목록:
    row_cells = table.add_row().cells
    row_cells[0].text = row['키1']
    row_cells[1].text = row['키2']

document.save('파일명.docx')
```

`python-docx`로 제목과 표를 만들고, 교정한 회의록을 한 줄씩 표에 추가해 `.docx` 파일로 저장했다.

같은 내용을 `json.dump()`로 JSON 파일, `- **이름** : 내용` 형식의 Markdown 파일로도 저장했다.

#### 7. GPT-4o로 이미지 설명하기

```python
import base64

def encode_image(image_path):
    with open(image_path, "rb") as image_file:
        return base64.b64encode(image_file.read()).decode("utf-8")

messages = [
    {
        "role": "user",
        "content": [
            {"type": "text", "text": "질문"},
            {"type": "image_url", "image_url": {"url": f"data:image/jpeg;base64,{base64_image}"}},
        ],
    }
]
```

`content`를 리스트로 만들어 텍스트와 이미지를 함께 보내면 GPT-4o가 이미지를 보고 답한다.

인터넷 이미지는 주소를 그대로 넣고, 내 PC의 이미지는 base64 문자열로 인코딩해 `data:image/jpeg;base64,...` 형식으로 넣는다.

`image_url`을 여러 개 넣으면 두 카페 사진의 차이점이나 2021년·2022년 OECD 연구개발비 그래프의 변화처럼 여러 이미지를 비교할 수 있다.

주가, 환율, 금리, 물가(CPI), 기업 실적, 비트코인 차트 6장을 캡처해 GPT-4o로 분석하고, 결과를 하나의 Markdown 보고서로 저장했다.

차트는 `.png`가 많아서 확장자에 따라 `image/png`, `image/jpeg`를 구분해 보냈고, 파일 이름에 공백이 있어 Markdown 이미지 경로를 `< >`로 감쌌다.

#### 핵심 정리

- `pymupdf`의 `get_text()`로 PDF 텍스트를 추출하고, `clip`으로 헤더·푸터를 제외할 수 있다.
- 프롬프트에 결과 형식을 미리 정해 주면 요약 결과를 원하는 구조로 받을 수 있다.
- Whisper의 `transcriptions`는 받아쓰기, `translations`는 영어 번역 받아쓰기를 한다.
- STT 결과는 오류가 있을 수 있어 요약문과 함께 GPT에 넘겨 교정할 수 있다.
- `python-docx`로 회의록을 표 형식의 Word 파일로 저장할 수 있다.
- 이미지는 `image_url`로 전달하며, 내 PC의 이미지는 base64로 인코딩해서 보낸다.
- 결과 형식을 검사하고 잘못되면 다시 요청하는 재시도 처리로 안정성을 높일 수 있다.
- `audio.speech.create()`로 문장을 음성 파일로 만들고, `voice`로 목소리를 바꿀 수 있다.
- 상대 경로는 실행하는 폴더 기준이므로, 파일 위치와 실행 위치를 맞춰야 한다.

- **근원물가상승률**: 2022년에 약 3%에서 2025년까지 소폭 하락하여 약 2%로 안정화.
- **생활물가상승률**: 2022년에 약 5%로 최대치를 기록한 후 2025년까지 약 3%로 감소.

### 금융적 의미 분석
이 데이터는 물가 상승률이 2022년을 정점으로 하락하는 추세를 보여줍니다. 이는 인플레이션이 정점을 지나 안정화되고 있음을 시사합니다. 투자자들에게는 인플레이션에 따른 불확실성이 줄어드는 긍정적인 신호일 수 있습니다. 기업은 비용 관리 및 가격 설정에 있어 좀 더 안정적인 환경을 기대할 수 있습니다. 경제 전체적으로는 인플레이션에 대한 압박이 완화되어 소비자 지출이 활성화될 가능성이 있습니다.

### 핵심 데이터 요약

- **매출원가:** 2021년에 1,664,113.4억 원에서 2025년 2,022,355.1억 원으로 증가, 전년 대비 8.4% 증가.

### 금융적 의미 분석
이 데이터는 해당 기업이 지속적인 성장을 보이고 있음을 시사합니다. 매출액과 매출총이익이 지속적으로 증가함에 따라 기업의 수익성이 향상되고 있음을 알 수 있습니다. 이는 투자자들에게 긍정적인 신호로 작용할 수 있으며, 기업의 안정적인 성장을 기대할 수 있습니다. 그러나 판매비와 관리비 또한 증가하고 있어, 비용 관리가 중요한 과제가 될 수 있습니다. 영업이익의 큰 폭의 성장은 기업의 효율적인 경영 성과를 나타내지만, 향후에도 비용 제어를 통해 지속적인 성장을 유지할 필요가 있습니다.

금융 이미지 6장을 GPT-4o로 분석해 보고서를 만들어 보니, 차트를 보고 기간, 축, 단위를 설명하고 핵심 수치를 정리한 뒤 금융적 의미까지 한 번에 작성해 주는 점이 편리했다.
</br>특히 물가(CPI) 그래프에서는 소비자물가, 근원물가, 생활물가 세 선을 구분해 2022년 정점 이후 하락하는 흐름을 정확히 짚었고, 금리 그래프에서도 2008년 금융위기 이후 인하, 2022년 이후 인상 흐름을 경제 상황과 연결해 설명했다.
</br>하지만 결과를 꼼꼼히 읽어 보니 틀린 부분도 있었다. 환율 그래프를 "특정 지수나 주가의 변화"라고 설명해 원/달러 환율이라는 것을 알아보지 못했고, 기업 실적 자료에서는 영업이익이 516,338.6억 원에서 436,010.5억 원으로 줄었는데도 "증가"라고 적었다.
</br>주가 차트의 "최저 가격 3,794.52 (50.39% 증가)"처럼 앞뒤가 맞지 않는 표현도 있었고, 비트코인 차트에서는 차트에 표시된 숫자를 그대로 옮겨 실제 가격과 맞는지 판단하기 어려웠다.
</br>GPT-4o가 이미지 속 숫자는 잘 읽어도 그 숫자가 무엇을 의미하는지, 늘었는지 줄었는지는 틀릴 수 있다는 것을 알게 되었고, AI가 만든 분석 결과는 원본 이미지와 직접 비교해 확인해야 한다는 것을 느꼈다.
</br>프롬프트에 "이미지에서 확인할 수 없는 내용은 추측하지 말라"는 조건을 넣었지만 오류를 완전히 막지는 못했기 때문에, 다음에는 이미지마다 "원/달러 환율 그래프"처럼 무엇을 캡처한 것인지 함께 알려 주거나 수치 비교는 따로 검증하는 단계를 추가하면 더 정확한 보고서를 만들 수 있을 것 같다.
