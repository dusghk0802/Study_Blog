# 99일차

## SpaceLink 주변 환경 분석·상가 추천·3D 일조량 지도 구현

📌 학습일 : 2026.11.25

📌 학습 내용 : 침수 흔적과 주변 시설 데이터 수집·연동, 위치 기반 환경 점수 및 수집 오류 처리, 상권·유동인구 점수와 추천 정렬 연결, 상가·오피스 업종 적합도 상세 분석, 매물 상세의 3D 주변 환경·사계절 일조량 지도 구현, main 브랜치 병합

---

#### 1. 주변 환경 데이터를 수집하고 매물 분석에 연결했다

매물 상세에서 주변 환경을 보여 주기 위해 침수 흔적과 주변 시설 데이터를 수집하는 흐름을 보강했다. 배치 수집 과정에서 데이터 형식을 맞추고, 침수 흔적을 공간 정보로 확인해 매물 주변 환경에 연결했다. 시설 데이터는 조회 결과를 위치 기준으로 정리해 매물과의 거리를 점수에 반영하도록 했다.

수집이 항상 성공한다고 가정하지 않도록 예외 처리도 추가했다. 주변 시설이 누락되거나 외부 API 요청이 실패한 상황을 정상 수집과 구분해 추적하고, 오류가 나도 전체 수집 흐름과 매물 화면이 불필요하게 중단되지 않도록 보완했다. 데이터가 없다는 사실과 수집에 실패했다는 사실은 다르게 관리해야 이후 재수집과 화면 안내가 가능하다는 점을 고려했다.

#### 2. 상권·유동인구 점수를 추천 정렬에 반영했다

상가 주변의 상권과 유동인구 정보를 조회해 점수로 제공하고, 그 결과가 상가 추천 순서에 반영되도록 API와 매물 목록을 연결했다. 점수 계산 결과가 상세 화면에만 머무르지 않고 목록 정렬까지 이어져야 추천 기능으로 사용할 수 있다.

추천 정렬을 연결하면서 상가 데이터 조회, 점수 계산, 화면 표시가 서로 다른 계층에 흩어져 있다는 점도 확인했다. 각 단계의 입력과 응답 기준을 맞춰야 화면에 표시되는 추천 결과를 설명할 수 있다.

#### 3. 상가·오피스 업종 적합도 상세 분석을 추가했다

상가와 오피스의 용도에 맞춰 업종 적합도를 계산하고, 세부 점수와 근거를 상세 화면에서 확인할 수 있도록 기능을 추가했다. 상권 점수 하나만 보여 주기보다 매물의 주변 조건이 특정 업종에 어떤 의미가 있는지 나눠서 설명하는 방향으로 구성했다.

점수는 결과만 표시하면 사용자가 이유를 알기 어렵다. 계산 항목과 기준을 함께 전달해야 추천을 검토하고 비교하는 데 도움이 된다는 점을 반영했다.

#### 4. 매물 상세에 3D 주변 환경·일조량 지도를 연결했다

매물 상세의 3D 일조량 보기에서 브이월드 3D 지도를 열도록 연동했다. 매물 좌표를 기준으로 주변 건물의 폴리곤과 높이 정보를 받아 3D 건물로 표현하고, 높이 값이 없는 경우에는 지상층수에 층고 기준을 적용해 보정하는 흐름을 넣었다. 선택 매물과 주변 건물을 구분해 볼 수 있도록 구성했다.

계절 대표일과 시간대를 선택하면 해당 시각의 태양 위치와 건물 그림자를 확인하도록 연결했다. 지도는 3D 장면으로 제공해 사용자가 확대·축소와 시점 조절을 하면서 주변 건물과 그림자를 볼 수 있게 했고, 계절·시간대 선택 UI는 기존 매물 상세 화면의 일조량 보기 영역 안에 배치했다. 좌표나 인증키가 없는 경우에는 지도를 열 수 없는 이유를 화면에 안내하도록 처리했다.

#### 5. main 브랜치의 변경사항을 병합했다

작업 브랜치에 main 브랜치 변경사항을 병합했다. 병합 중 InquiryService.java에서 발생한 충돌을 확인해 두 브랜치의 변경 의도를 반영해 해결했다. 이 과정에서 내 기능만 동작하는지 보는 것으로 끝내지 않고, 다른 화면과 API 변경사항이 함께 들어온 상태에서 프로젝트를 통합하는 작업도 진행했다.

![99일차 작업 화면](./day_99.png)

오늘 작업을 통해 주변 환경 기능은 데이터 수집부터 공간 기준 매칭, 점수 계산과 화면 표시까지 이어져야 사용자에게 의미가 있다는 점을 배웠다. 외부 데이터가 비어 있는 경우와 요청 실패를 나눠 관리해야 재수집과 오류 안내를 제대로 할 수 있고, 추천 점수는 상세 분석과 목록 정렬의 기준이 일치해야 한다. 업종 적합도는 점수뿐 아니라 판단 근거도 함께 보여 줘야 하며, 3D 일조량 분석은 건물 위치와 높이, 날짜·시간별 태양 위치, 지도 조작이 함께 맞아야 자연스럽게 동작한다.

주변 환경 데이터를 모으는 일부터 추천과 상세 화면, 3D 일조량 지도까지 여러 기능을 연결하며 API 응답과 점수 기준, 화면 상태를 함께 맞추는 일이 중요하다고 느꼈다. 특히 3D 지도는 장면을 띄우는 것만으로 끝나지 않고 실제 좌표와 건물 높이, 계절과 시간대가 화면에 반영되어야 분석 기능으로 쓸 수 있었다. 앞으로도 화면뿐 아니라 데이터 흐름과 실패 상황까지 살펴보고, 병합할 때는 양쪽 변경의 의도를 확인해 기존 기능과 자연스럽게 통합해야겠다.
