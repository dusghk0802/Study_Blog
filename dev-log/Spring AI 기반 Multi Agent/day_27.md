## 미니 프로젝트 - CINEHUB 백엔드 및 데이터베이스 설계

📌 학습일 : 2026.08.25

📌 학습 내용 : 데이터베이스 구조 설계, 테이블 관계 설정, 백엔드 구조 설계, 기능별 데이터 처리 구조 구성

---

#### 1. 데이터베이스 구조 설계

CINEHUB 서비스에서 필요한 데이터를 관리하기 위해 데이터베이스 구조를 설계하였다.

서비스의 주요 기능을 기준으로 필요한 테이블을 구분하고 각 테이블에서 관리해야 하는 데이터를 정리하였다.

주요 테이블은 다음과 같이 구성하였다.

- users : 회원 정보
- movies : 영화 정보
- posts : 게시글 정보
- comments : 댓글 정보
- 추천 관련 테이블
- 찜 관련 테이블
- 신고 관련 테이블

#### 2. 테이블 관계 설정

회원, 영화, 게시글, 댓글 등의 데이터가 서로 연결될 수 있도록 테이블 간의 관계를 설계하였다.

기본적으로 다음과 같은 데이터 흐름을 기준으로 관계를 구성하였다.

`users` → `movies` → `posts` → `comments` → 추천·찜·신고 관련 테이블

각 테이블의 기본키와 외래키를 이용하여 데이터 간의 관계를 연결할 수 있도록 구조를 설계하였다.

#### 3. 백엔드 구조 설계

웹 페이지에서 요청한 데이터를 데이터베이스에서 조회하고 처리할 수 있도록 백엔드의 기본 구조를 구성하였다.

기능별로 필요한 데이터 처리 과정을 구분하고 이후 데이터베이스와 연결할 수 있도록 기본적인 코드 구조를 작성하였다.

#### 4. 기능별 데이터 처리 구조 구성

서비스에서 사용할 주요 기능을 기준으로 필요한 데이터 처리 기능을 정리하였다.

- 회원 정보 조회 및 관리
- 영화 정보 조회
- 게시글 등록, 조회, 수정, 삭제
- 댓글 등록, 조회, 수정, 삭제
- 영화 찜 등록 및 삭제
- 게시글 추천 처리
- 게시글 및 댓글 신고 처리
- 마이페이지 사용자 활동 정보 조회

현재는 실제 데이터를 등록하기 전 단계이므로 각 기능에서 필요한 데이터와 처리 구조를 먼저 구성하였다.

#### 핵심 정리

- CINEHUB 서비스에 필요한 데이터베이스 구조를 설계하였다.
- 테이블별 역할과 저장할 데이터를 구분하였다.
- 기본키와 외래키를 이용한 테이블 관계를 설계하였다.
- 백엔드에서 처리해야 할 주요 기능을 정리하였다.
- 이후 실제 데이터를 추가하고 Java와 Oracle DB를 연동하여 기능을 구현할 예정이다.
