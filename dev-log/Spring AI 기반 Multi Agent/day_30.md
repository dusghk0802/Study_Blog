# 30일차

## CINEHUB 프로젝트 통합 및 발표 준비

📌 학습일 : 2026.08.28

📌 학습 내용 : 프로젝트 통합, 실행 환경 확인, 기능 점검, 프로젝트 발표 자료

---

#### 1. 프로젝트 최종 통합

팀원별로 구현한 기능을 하나의 프로젝트로 통합하고 전체 프로젝트 구조를 확인하였다.

- 프론트엔드와 백엔드 기능 통합
- Oracle DB 연동 확인
- 영화 검색 및 추천 기능 통합
- 커뮤니티 및 관리자 기능 통합
- 프로젝트 파일 및 폴더 구조 정리

#### 2. 프로젝트 실행 환경 확인

통합된 프로젝트 파일을 내려받아 로컬 환경에서 실행하는 과정을 확인하였다.

프로젝트를 새로 내려받은 경우 개발 환경이나 라이브러리, DB 연결 등의 설정이 기존 환경과 다를 수 있기 때문에 실행에 필요한 설정을 다시 확인하였다.

또한 VS Code에서 프로젝트 폴더가 `Restricted Mode`로 실행되는 경우 일부 기능이 제한될 수 있다는 것을 확인하였다.

#### 3. 프로젝트 주요 기능 점검

최종 프로젝트에서 구현한 주요 기능과 전체적인 서비스 흐름을 다시 확인하였다.

- 영화 탐색 및 상세 정보
- AI 기반 영화 추천
- 커뮤니티 게시판
- 댓글 및 좋아요
- 마이페이지
- 관리자 기능
- 회원 및 영화 데이터 관리

#### 4. 데이터베이스 구조 정리

프로젝트 발표를 위해 CINEHUB에서 사용하는 주요 테이블과 데이터의 관계를 다시 정리하였다.

```text
USERS
MOVIES
POSTS / COMMENTS
REPORTS / ADMIN_LOGS
MOVIE_GENRES / MOVIE_LIKES

---

어느정도 프로젝트가 끝난 줄 알았는데 팀원들이 추가적으로 더 넣고 싶다는 요청에 메뉴가 2개정도 더 생겨서 전체적으로 다시 정리를 해야 할것 같다.

내일이나 월요일쯤에 데이터베이스 구조 정리랑 피피티를 다시 정리해야 할것 같다.
