## 🎞️ CINEHUB

> **영화를 보는 것에서 끝나지 않고, 영화에 대한 경험을 함께 나누는 공간**

CINEHUB는 영화 정보를 확인하는 것에서 끝나는 기존 영화 정보 서비스에서 나아가
**영화 정보와 커뮤니티 기능을 하나의 서비스로 연결한 웹 프로젝트**입니다.

사용자는 원하는 영화의 정보를 확인하고 관심 있는 영화를 저장할 수 있으며,
커뮤니티를 통해 다른 사용자들과 영화에 대한 다양한 의견을 공유할 수 있습니다.

## 🎯 Project Goal

### 01. 영화 정보를 한곳에서

사용자가 여러 사이트를 이동하지 않고
원하는 영화의 기본 정보를 확인할 수 있도록 합니다.

### 02. 관심 있는 영화 저장

보고 싶은 영화나 관심 있는 영화를 찜하여
마이페이지에서 다시 확인할 수 있도록 합니다.

### 03. 영화에 대한 의견 공유

게시글과 댓글을 통해 다른 사용자들과
영화에 대한 감상과 의견을 자유롭게 공유할 수 있도록 합니다.

### 04. 정보와 커뮤니티의 연결

단순한 영화 정보 제공을 넘어
**영화 탐색 → 관심 영화 저장 → 커뮤니티 참여**로 이어지는 서비스를 구현합니다.

## 🗃️ Database

CINEHUB의 데이터베이스는 회원, 영화, 커뮤니티를 중심으로 구성합니다.

```text
USERS
  │
  ├──── FAVORITES ──── MOVIES
  │
  └──── POSTS
          │
          ├──── COMMENTS
          ├──── LIKES
          └──── REPORTS
```

### 주요 테이블

|     테이블     | 역할       |
| :---------: | -------- |
|   `USERS`   | 회원 정보    |
|   `MOVIES`  | 영화 정보    |
|   `POSTS`   | 커뮤니티 게시글 |
|  `COMMENTS` | 게시글 댓글   |
| `FAVORITES` | 영화 찜     |
|   `LIKES`   | 게시글 추천   |
|  `REPORTS`  | 게시글 신고   |
