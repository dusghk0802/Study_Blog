## 🎞️ CINEHUB

> **영화를 찾는 것에서 끝나지 않고, 취향에 맞는 영화를 추천받고 이야기를 나누는 공간**

CINEHUB는 영화 정보 제공과 커뮤니티 기능에
**AI 알고리즘 기반 영화 추천 기능을 결합한 웹 서비스**입니다.

사용자는 다양한 영화 정보를 확인하고 관심 있는 영화를 저장할 수 있으며,
AI 추천 기능을 통해 자신의 취향에 맞는 영화를 추천받을 수 있습니다.

또한 커뮤니티를 통해 다른 사용자들과 영화에 대한 감상과 의견을 자유롭게 공유할 수 있습니다.

## 🎯 Project Goal

### 01. 영화 정보를 한곳에서

사용자가 원하는 영화의 기본 정보를
한곳에서 편리하게 확인할 수 있도록 합니다.

### 02. AI 기반 맞춤 영화 추천

AI 알고리즘을 활용하여 사용자의 취향과 데이터를 분석하고
**사용자에게 적합한 영화를 추천**합니다.

단순한 영화 목록 제공을 넘어 사용자가 새로운 영화를 발견할 수 있도록 합니다.

### 03. 관심 있는 영화 저장

보고 싶은 영화나 관심 있는 영화를 찜하여
마이페이지에서 다시 확인할 수 있도록 합니다.

### 04. 영화에 대한 의견 공유

게시글과 댓글을 통해 다른 사용자들과
영화에 대한 감상과 의견을 자유롭게 공유할 수 있도록 합니다.

### 05. 영화 서비스 기능의 통합

**영화 탐색 → AI 영화 추천 → 관심 영화 저장 → 커뮤니티 참여**

과정을 하나의 서비스 안에서 이용할 수 있도록 구현합니다.

## 🤖 AI Movie Recommendation

<div align="center">

### 사용자에게 맞는 영화를 찾아주는 AI 추천 기능

</div>

CINEHUB는 사용자가 직접 모든 영화를 탐색해야 하는 불편함을 줄이기 위해
**AI 알고리즘 기반 영화 추천 기능**을 제공합니다.

```text
👤 사용자 데이터
       │
       ▼
📊 사용자 취향 분석
       │
       ▼
🤖 AI 추천 알고리즘
       │
       ▼
🎯 추천 영화 선정
       │
       ▼
🎬 사용자 맞춤 영화 제공
```

### 주요 기능

* 사용자 데이터를 활용한 영화 취향 분석
* AI 알고리즘을 통한 추천 영화 선정
* 사용자별 맞춤 영화 제공
* 새로운 영화 탐색 지원

## 🗃️ Database

CINEHUB의 데이터베이스는 회원, 영화, 커뮤니티를 중심으로 구성합니다.

```text
USERS
  │
  ├──── FAVORITES ──── MOVIES
  │
  └──── POSTS
          │
          ├──── COMMENTS
          ├──── LIKES
          └──── REPORTS
```

### 주요 테이블

|     테이블     | 역할       |
| :---------: | -------- |
|   `USERS`   | 회원 정보    |
|   `MOVIES`  | 영화 정보    |
|   `POSTS`   | 커뮤니티 게시글 |
|  `COMMENTS` | 게시글 댓글   |
| `FAVORITES` | 영화 찜     |
|   `LIKES`   | 게시글 추천   |
|  `REPORTS`  | 게시글 신고   |
