1. .env.example을 복사해 .env를 만듭니다.
   copy .env.example .env

2. .env의 MYSQL_ROOT_PASSWORD에 충분히 길고 고유한 비밀번호를 입력합니다.
   .env는 Git에 올리지 않습니다.

3. Spring Boot 실행 JAR을 만듭니다.
   .\gradlew clean bootJar

4. MySQL과 앱 컨테이너를 빌드하고 실행합니다.
   docker compose up --build

5. 종료하려면 다음 명령을 실행합니다.
   docker compose down
